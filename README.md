# Customer Churn Analysis

## Overview
Analysis of 10,000 bank customer records to understand
why customers leave the bank using SQL.

## Tools & Skills Used
- MySQL Workbench
- SQL (Structured Query Language)
- Aggregate Functions (COUNT, SUM, AVG)
- GROUP BY & HAVING
- CASE statements & Subqueries

## Project Structure 
| Database setup & data import |
| Basic queries — SELECT, WHERE, ORDER BY |
| Aggregate functions — COUNT, SUM, AVG |
| GROUP BY analysis |
| CASE statements, subqueries, string functions |

## Files
| import-data.sql | Database setup & table creation |
| Churn-rate-analysis.sql | All analysis queries |
| customer-churn-record.csv | Original dataset |

## Key Findings
1. Overall churn rate is 20.37% (2,037 out of 10,000)
2. Germany has the highest churn rate at 32.4%
3. Senior customers churn the most across all countries
4. Germany Senior customers have the highest churn at 59.8%
5. Female customers have a higher churn rate than male
6. Customers with 3+ products churn significantly more
